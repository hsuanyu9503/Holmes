# 606 情報局 v2.6.0 R1｜近距／遠距模式分流

## 本版已完成

- 在連線模式的建立房間畫面選擇「近距任務」或「遠距任務」。
- 遠距可選擇自由討論「主控手動結束」或「限時討論」；限時為 3／5／8／10 分鐘。**R1 僅儲存設定，限時執行會在 R3 開發。**
- 新建與重新連線取得的房間狀態皆包含 `play_mode`、`discussion_mode`、`discussion_seconds`。
- 原單機模式、原近距遊戲流程、3×3／4×4 情報卡、雙色骰子、代碼表及 QR code 保留。
- 遠距建立房間後可完成：加入、確認身分、擲骰、抽情報卡，並進入新的 `clue`（等待線索傳輸）階段。R1 **不提供發言／討論／投票**，避免將尚未完成的功能誤當成可玩版本。
- 頁首徽章使用縮小圖檔以降低連線首頁初始下載量，其餘單機圖片未修改。
- v2.5.7 舊版建立房間 RPC 不刪除，便於檢查向後相容。

## 資料庫部署：兩種方式擇一

**既有 v2.5.7 統一版**：執行 `supabase/606-intelligence-v2.5.7-to-v2.6.0-R1.sql`。

**全新 Supabase 專案**：只需執行 `supabase/606-intelligence-v2.6.0-R1-full.sql`，內容含 v2.5.7 基準及 R1 擴充，不須額外跑舊版檔案。

注意：SQL 在有進行中房間時會中止並回滾。請先結束該輪並回到等待區，或結束房間。執行前建議備份。若網站先更新卻沒有執行 R1 SQL，建立房間會失敗。

## 網站部署

上傳 ZIP 根目錄中的網站檔案到 GitHub Pages：`index.html`、`online.html`、`online-config.js`、完整 `assets/`。保留你已儲存在瀏覽器的 Supabase 設定；不需把 Secret 或 Service Role Key 放到網站。

`supabase/` 是資料庫部署檔，不需要發布到網站。將其留在部署壓縮包中是方便版本維護。
