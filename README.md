# 606 情報局｜v2.6.0 R3 遠距自由討論與計時系統

本版基於已驗收的 **v2.6.0 R2**，新增遠距聊天、兩種討論時間模式與主控管理。**單機模式、近距連線模式、R2 正式線索提交、身分保密、共用代碼表與骰子規則均保留。**

## 部署方式（SQL 勿兩份都執行）

- **既有 R2 Supabase 專案**：先結束所有進行中的房間並備份，再執行 `supabase/606-intelligence-v2.6.0-R2-to-R3.sql`。
- **全新 Supabase 專案**：只執行 `supabase/606-intelligence-v2.6.0-R3-full.sql`，其中已包含 v2.5.7～R3 的必要結構與函式。
- 必須在 Supabase Authentication 啟用 Anonymous Sign-ins；前端只填 Project URL + **publishable / anon 公開金鑰**，嚴禁使用 secret / service_role。
- SQL Editor 執行完成後，再將 `index.html`、`online.html`、`online-config.js` 與 `assets/` 全部更新至 GitHub Pages。請確認 `online.html` 載入的是 `assets/online-v2.6.0-R3.js` 與 `assets/online-v2.6.0-R3.css`。
- 網頁底部顯示 `v2.6.0 R3`；必要時硬重新整理。升級 SQL 不會主動刪除情報卡、成員或房間，但禁止在進行中的遊戲上直接升級。

## 本版流程

1. 房主建立**遠距房間**並選「手動結束」或「限時3／5／8／10分鐘」；各玩家加入、確認身分、抽骰及抽情報卡。
2. R2 依座位提交線索，最後一人完成後由**主控按「開始自由討論」**。
3. 所有玩家在同一聊天頻道收發訊息（每則1～200字，每位玩家至少相隔2秒、每房每輪最多200則；畫面顯示最近100則）；主控可以查看、但不以玩家身分發言。
4. 手動模式：由主控按「結束討論」。限時模式：顯示由伺服器截止時間計算的同步倒數，主控可暫停／繼續、延長1或3分鐘、提前結束。
5. 討論封存後停在 **`vote_pending`（等待 R4 秘密投票）**，不會進入現有的近距臥底揭曉流程。

## 重要實作說明

- 聊天資料在非公開 `intelligence_private.intel606_messages`，不開放直接查詢或 Realtime 訂閱。發送者、長度、頻率、階段和截止時間由 `intel606_send_chat` RPC 驗證。
- 限時結束由 Supabase 資料庫時鐘判斷。**有任何合法房間參與者在線時**，透過每5秒的房間讀取或到點補讀觸發 `chat → vote_pending`；不需要房主始終在線。**全部人都離線**時不設背景 cron 排程，但重新進入讀取狀態後會立即依截止時間封存，且過期後不能再送出訊息。
- 「暫停」代表同時停止倒數與新的聊天訊息；繼續後恢復。
- 聊天紀錄跨斷線可從資料庫讀回（僅傳最近100則）；每輪訊息與房間同步資料不含未揭露臥底、秘密代號或其他玩家的私人碼表。
- R3 不新增觀察者、主控兼玩家、秘密投票、臥底猜測或評分功能。這些留在後續獨立階段。
- 舊版前端不能理解 R3 新階段，因此升級 SQL 與網頁須同批部署；若要退版，需使用相容的資料庫 migration，而非只回退前端。
