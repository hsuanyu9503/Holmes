# 606 情報局 v2.6.0 R1.1｜身分卡提示一致化

## 本次調整（僅前端）

- 在「確認身分」及後續階段，情報員與臥底的私人情報入口、提示文字完全一致。
- 開啟私人角色卡後，情報員仍可看到資料庫分發的共用代碼表；臥底在相同區塊看到「你/妳的手中沒有機密代碼對照表，想辦法蒐集線索破解機密代碼吧！」。
- 保留原有的確認收妥、公開骰子、情報卡、房間管理及遠距 R1 階段。
- 沒有更動 Supabase SQL、RPC、角色權限，臥底仍不會從伺服器收到代碼表。

## 部署

以 R1 為基礎，將新版 `online.html` 和 `assets/online-v2.6.0-R1.1.js`、`assets/online-v2.6.0-R1.1.css` 一起上傳 GitHub Pages。`index.html` 與其他檔案可保留，但提供完整包方便直接覆蓋。

**不需要執行 SQL。** 資料庫維持 R1 版本。更新後重新整理網頁，檢查頁尾 `v2.6.0 R1.1`。

## 版本基礎

此版本以 `v2.6.0 R1` 修改，只修正角色身分提示，不含 R2 的線索提交功能。完整部署 SQL 與 R1 文件仍附於 `supabase/`，方便全新環境部署，既有專案請勿重跑。
